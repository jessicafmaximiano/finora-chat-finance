# Finora: Seu Parceiro Financeiro

Quero criar o conceito de um aplicativo chamado Finora, um assistente de organização de finanças pessoais baseado em conversas em linguagem natural.

Problema:

Muitas pessoas abandonam o controle financeiro porque os aplicativos exigem preenchimento manual, classificação de despesas e interpretação de relatórios complexos.

Público-alvo:

Pessoas iniciantes em organização financeira, trabalhadores autônomos e pessoas com diferentes fontes de renda.

Funcionalidades principais:

1. Registrar gastos por meio de frases como “gastei R$ 35 no mercado”.

2. Classificar automaticamente as transações.

3. Mostrar saldo, entradas e saídas.

4. Criar e acompanhar metas financeiras.

5. Oferecer dicas personalizadas de economia.

6. Exibir relatórios simples e acessíveis.

Agente Financeiro:

Deve usar português brasileiro, tom acolhedor, educativo, objetivo e sem julgamentos.

Antes de implementar qualquer tela, apresente:

- as cinco funcionalidades prioritárias do MVP;

- o fluxo conceitual das telas;

- o comportamento do Agente Financeiro;

- os recursos necessários;

- um plano simples para validar o produto com usuários.
